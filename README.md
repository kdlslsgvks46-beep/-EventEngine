# EventEngine

Движок для создания ивентов с конфигурацией в YAML. Позволяет добавлять новые ивенты без перекомпиляции плагина.

## 🎉 Возможности
- **Создание ивента**: `/event create <имя> <тип> <длительность>`.
- **Запуск**: `/event start <имя>` (оповещение всех игроков).
- **Остановка**: `/event stop <имя>`.
- **Список активных**: `/event list` (показывает оставшееся время).
- **Гибкая логика**: Примеры ивентов ("Двойные монеты", "Взрывной дроп") хранятся в `events.yml`.

## ⚙️ Установка
1. Скачайте `EventEngine.jar`.
2. Поместите в `plugins`.
3. Перезапустите сервер.
4. Создайте ивент и запустите его.

## 🧠 Технологии
- Java 25
- Paper API 1.21+
- Парсинг YAML и динамическая логика событий.
